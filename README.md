# JobBeeper Local

Personal, free-first job discovery engine.

## Current capabilities
- Greenhouse, Lever, Ashby, SmartRecruiters, Workable and Workday.
- Best-effort public connectors for LinkedIn guest search, Naukri public search and Instahyre public search.
- Remotive, RemoteOK, Arbeitnow and optional Adzuna.
- Title/location/experience/freshness/skill filters.
- Match scoring and Telegram alerts.
- Dashboard feed generated by GitHub Actions.
- Dashboard auto-refreshes every 30 seconds; no manual browser refresh is required.
- GitHub Actions polls the sources every ~10 minutes.

## Dashboard
Enable GitHub Pages for the repository using GitHub Actions. The Pages workflow publishes `dashboard/`.

## Important source note
LinkedIn's public guest jobs endpoint is not a guaranteed/stable API and may be rate-limited or changed. Naukri and Instahyre public pages can also change. These adapters are deliberately best-effort and the ATS APIs remain the most reliable sources.

## Telegram
Create a bot with BotFather, then add `TG_TOKEN` and `TG_CHAT_ID` as GitHub Actions secrets.

## Free-first architecture
GitHub Actions + static GitHub Pages + repository JSON state. No paid server is required for the personal version.
