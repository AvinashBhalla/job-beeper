The dataset contains employer board slug candidates for Greenhouse, Ashby and Lever. Its original crawled/last-crawled dates are preserved. It may be used commercially with attribution under CC BY 4.0, but a listed board is not necessarily live today. JobBeeper imports these rows only as low-confidence, unverified candidates. Each board must be verified before activation.

This file does not grant rights to the underlying job postings or to other datasets linked from the source repository.
